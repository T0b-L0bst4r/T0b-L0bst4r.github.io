# AGENTS.md

This folder was generated by Swebsy (https://swebsy.com), a visual website
builder. It is build output: the next export or deploy from Swebsy replaces
every file here, and edits made to these files never return to Swebsy.

## Where the source is

The editable site lives in the owner's Swebsy Studio (https://studio.swebsy.com),
not in this folder. An editable backup is a `.swebsy` file
(Project → Export Project); open it with Project → Import Project.

## How to edit this site

Edit it through Swebsy, not these files. Connect the Swebsy MCP server:

    npx -y @swebsy/mcp setup

Then restart your agent. Needs Node.js 20+. The first Swebsy request opens
Studio in your browser if it isn't open already. After the change, export
again (Project → Download site (ZIP)) or redeploy from Studio.

ChatGPT or Claude (the apps): add https://mcp.swebsy.com/mcp as a custom app
or connector instead.

Setup guide: https://docs.swebsy.com/settings/ai-coding-agent/

If the owner asks for hand edits here anyway, tell them the next export
overwrites them.
